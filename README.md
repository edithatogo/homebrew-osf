# homebrew-osf

Homebrew tap for [OSF CLI Go](https://github.com/edithatogo/osf-cli-go).

```sh
brew tap edithatogo/osf
brew install osf-cli-go
osf --version
```

The formula installs the signed v0.3.2 CLI binary for supported macOS and
Linux architectures and verifies the release SHA-256 checksum through
Homebrew's formula download process.
